# 防撤回补发

默认开启。有人撤回消息后，在原群聊或私聊发送：

```text
撤回的消息是：原来的文字
```

图片、语音、视频和表情用 `[图片]` 等类型提示；文件显示文件名（可用时），合并转发显示 `[合并转发]`。本插件不重发附件，也不调用大模型、人格或语音合成。

`anti_recall_image` 和 `anti_recall_file` 是默认开启的两个独立插件，分别重新发送已下载的图片和文件。对应插件开启时，本插件省去图片/文件的类型文字提示，避免多发一条消息。关闭文本插件不影响两个附件插件；关闭附件插件后，本插件恢复对应的文字提示。

只处理插件启用后收到且仍在缓存中的原消息，每个插件实例最多缓存 1000 条。撤回通知里的原生消息 ID 偶尔会和缓存对不上；这时如果同群、同发送者、最近 5 分钟内只有一条未撤回原文，会按这条原文兜底。无法唯一确定时不发送，避免补错消息。重复撤回通知只补发一次。账号连接、群聊和私聊分别匹配，不跨会话查找，也不执行原文中的指令。插件卸载或重载会清空缓存。

在网页“插件管理”开关 `anti_recall`；控制台也可输入 `disable anti_recall` 或 `enable anti_recall`。会话白名单仍然生效。关闭插件后，管理台仍保留原来的“已撤回”标记。
