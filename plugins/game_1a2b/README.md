# 1A2B 小游戏

发送 `1A2B` 开始一局，机器人会随机生成一个由 4 个不重复数字组成的答案，并回复规则。

开局后，任何发送内容在去除空白字符后正好是 4 位纯数字的聊天记录都会被当作一次猜测：

- `A`：数字和位置都正确
- `B`：数字正确但位置不对

猜错时回复 `xAyB`；猜中时回复：

```text
恭喜回答正确！🎉🎉🎉
本次累计猜测xx次
您本次共猜测xx次
玩家A：3次
玩家B：2次
```

最后按猜测次数从多到少列出本局每位玩家。

每个群聊、每个私聊各自独立一局；同一会话内的所有玩家共享答案和猜测次数。每局限时 3 分钟，超时自动结束并公布答案；对局进行中再次发送 `1A2B` 不会重开，只会提示剩余倒计时。
