# 艾特机器人对话

从微信成员列表真正艾特机器人，再附上问题，即可触发回复。只键入看起来像 `@昵称` 的普通文字不会触发；艾特别人也不会触发。

上下文为本群最近最多 200 条有效文字，可能来自不同成员，不混入其他群、控制指令和机器人的输出。每条上下文带发言者昵称和时间；如果同时真实艾特了群友，还会附带这些群友各自最近最多 100 条群聊，供“锐评 @某人”这类请求使用。回复采用本群当前人格，文字回复会真正艾特原发言者。

显示名字优先使用该成员的本群绑定，未绑定时使用缓存中取得的微信名。功能需要成员记录、有效的模型配置和启用的 `mention_chat` 插件。

清空、跨天、账号切换或人格变化会取消尚未发出的旧回复。

同时启用 `voice_reply`、填写自己的 Fish Audio 配置并在群里选择音色后，回复会合成为微信语音条；成功时只发语音，合成失败时回退文字。配置和指令见[语音回复插件](../voice_reply/README.md)。
